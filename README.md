# Govika M | Developer Portfolio

Modern, interactive developer portfolio and ATS-friendly resume showcase built with React 19, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Interactive ATS Resume Modal**: Dual-mode resume viewer (Dark UI & ATS Document View) with one-click plain-text copy, print-to-PDF engine, and direct hash URL access (`#resume`).
- **Showcase Projects**: Detailed cards highlighting military image steganography, smart agriculture, algorithms, tech stacks, and source links.
- **Dynamic Skills & Stack**: Categorized visual display for Python, Django, Flask, Databases (PostgreSQL, MySQL), Developer Tools, and DSA.
- **Rich Aesthetics**: Floating particle effects, glassmorphism cards, glowing status tags, and smooth Framer Motion entrance animations.
- **Coding Profiles**: Quick links to GitHub, LinkedIn, LeetCode, and HackerRank.
- **Contact Form**: Direct messaging and mailto fallback.

## 🛠️ Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Custom Modern CSS Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React, React Icons

## 💻 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Govika1002/Portfolio_2.git
   cd Portfolio_2
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Generate Downloadable PDF Resume**:
   ```bash
   npm run generate-pdf
   ```
